# Doc

Use for reading, creating, editing, or reviewing .docx documents, especially when formatting and layout fidelity matter. Prefer python-docx and render the result for visual inspection when available.

## What this skill covers

- Practical guidance for applying doc workflows.
- A consistent process for reviewing requirements, making decisions, and validating results.
- Use the instructions in `SKILL.md` as the primary reference.

## Installation

Add this skill directory to the skills location supported by your AI coding assistant, then make the skill available to the assistant.

## Usage

Invoke the skill when working on tasks related to doc. Provide the relevant project context, constraints, and expected outcome. Review generated changes before applying them.
