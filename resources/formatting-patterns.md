# DOCX Formatting Patterns

## Semantic styles

| Element | Suggested Word style |
|---|---|
| Document title | Title |
| Main section | Heading 1 |
| Subsection | Heading 2 |
| Nested subsection | Heading 3 |
| Body | Normal |
| Bulleted item | List Bullet |
| Numbered step | List Number |
| Table caption | Caption |

Keep heading levels logical. Do not skip levels just to obtain a particular font size.

## Page setup
- Use the requested page size. Otherwise preserve the template or choose a common regional default.
- Keep margins consistent.
- Use landscape orientation only when wide content requires it.
- Do not shrink text excessively to force content onto fewer pages.

## Paragraphs
Use consistent line spacing and paragraph spacing. Keep headings with the next paragraph where possible. Avoid repeated empty paragraphs as a spacing mechanism.

## Tables
Use concise headings, consistent numeric alignment, deliberate vertical alignment, adequate cell padding, and explicit widths when needed. Check that the table fits within page boundaries. Avoid unnecessary merged cells and nested tables.

## Headers and footers
Use headers for document identity or section context. Use footers for page numbers, dates, or confidentiality labels when requested. Keep them restrained and away from page edges.

## Images
Preserve aspect ratio, use suitable width, add descriptive alternative text where supported, keep captions close, and verify placement after rendering.

## Fields
Page numbers, tables of contents, and cross-references may be Word fields. A library can insert field codes without calculating displayed values. Use a compatible office application to update fields when required.

## Accessibility
Use real heading styles and descriptive hyperlink text. Do not rely on color alone. Add meaningful alt text to informative images. Keep tables simple and maintain sufficient text/background contrast.
